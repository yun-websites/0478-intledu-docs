<ParagraphTitle id="4-1-1-system-software-and-application-software">系统软件和应用软件</ParagraphTitle>

<ParagraphContent id="4-1-1-system-software-and-application-software">
所有计算机最初都是一组相互连接的硬件。没有软件，硬件就无法发挥作用。软件分为**系统软件**和**应用软件**。

系统软件的主要功能：

- 控制和管理计算机硬件的运行；
- 提供运行其他软件的平台；
- 使硬件和软件能够正常协同工作；
- 提供人机界面（HCI）；
- 管理硬件资源的分配和使用。

应用软件用于执行计算机上的各种应用，让用户利用计算机资源完成特定任务。它可以是单个程序，例如记事本，也可以是程序套件，例如 Microsoft Office；用户可在需要时运行它。

典型应用软件包括文字处理器、电子表格、数据库、互联网浏览器和游戏软件。
</ParagraphContent>
