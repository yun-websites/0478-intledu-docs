<ParagraphTitle id="4-1-4-interrupts">Interrupts</ParagraphTitle>

<ParagraphContent id="4-1-4-interrupts">
An interrupt is a signal sent from a device or software to the microprocessor. The processor temporarily pauses its current work so that it can service the interrupt.

Interrupts may be caused by:

- a timing signal;
- an input/output process, such as a disk drive or printer requiring more data;
- a hardware fault, such as a paper jam;
- user interaction, such as a keyboard command;
- a software error, such as a missing executable file, two processes accessing the same memory location, or division by zero.

The computer identifies the interrupt type and determines its priority. The processor then either resumes its previous task or services the device or program that caused the interrupt.

Interrupts allow several tasks to appear to run at the same time. For example, a computer can download a file while playing music. In reality, the processor moves data in and out of memory rapidly and services the tasks in turn.

A **buffer** is a memory area that stores data temporarily. When downloading a movie, a buffer compensates for differences between the download rate and the rate at which the media player uses the data. The download rate into the buffer must be greater than the rate at which data leaves the buffer; otherwise the movie may freeze.
</ParagraphContent>
