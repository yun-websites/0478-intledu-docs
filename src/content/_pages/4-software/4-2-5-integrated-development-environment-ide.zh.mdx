<ParagraphTitle id="4-2-5-integrated-development-environment-ide">集成开发环境（IDE）</ParagraphTitle>

<ParagraphContent id="4-2-5-integrated-development-environment-ide">
**集成开发环境**（Integrated Development Environment，IDE）用于辅助程序员编写和开发程序。有些 IDE 只支持一种编程语言，有些支持多种语言，例如 Python 的 PyCharm、Visual Basic 的 Visual Studio 和 Java 的 BlueJ。

IDE 通常包含以下功能：

- 代码编辑器；
- 翻译程序；
- 带调试器的运行环境；
- 错误诊断；
- 自动补全；
- 自动纠错；
- 自动生成文档和代码美化。

**代码编辑器**允许程序员直接编写和修改程序，不必在 IDE 和独立文本编辑器之间切换，因此可以加快开发过程。

IDE 通常提供编译器或解释器，使程序能够运行。开发程序时常使用解释器；准备最终版本时可使用编译器生成可执行程序。

**调试器**可以运行开发中的程序，让程序员逐行执行代码（单步执行），或设置断点，使程序在源代码的指定位置暂停，从而检查程序的运行过程。
</ParagraphContent>
