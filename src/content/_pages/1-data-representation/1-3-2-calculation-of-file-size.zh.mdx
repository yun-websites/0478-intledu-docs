<ParagraphTitle id="1-3-2-calculation-of-file-size">文件大小的计算</ParagraphTitle>

<ParagraphContent id="1-3-2-calculation-of-file-size">

本节讨论存储位图图像和声音样本所需的文件大小。

图像文件大小的计算式为：

```text
图像分辨率（像素）× 色彩深度（位）
```

单声道声音文件大小的计算式为：

```text
采样率（Hz）× 采样分辨率（位）× 样本长度（秒）
```

立体声声音文件还需要将结果乘以 `2`。

**示例 1**

一张照片为 `1024 × 1080` 像素，使用 32 位色彩深度。一个 `64 GiB` 的 U 盘可存放多少张这种尺寸的照片？

1. 将垂直和水平方向的像素数相乘，得到像素总数：`1024 × 1080 = 1105920 pixels`。
2. 将像素总数乘以色彩深度，再除以 `8`，得到字节数：`1105920 × 32 = 35389440 bits`；`35389440 / 8 = 4423680 bytes`。
3. `64 GiB = 64 × 1024 × 1024 × 1024 = 68719476736 bytes`。
4. 用 U 盘容量除以文件大小：`68719476736 / 4423680 = 15534 photos`。

**示例 2**

一台相机的传感器阵列为 `2048 × 2048` 像素，使用 16 位色彩深度。求该相机拍摄图像的大小，单位为 MiB。

1. 将垂直和水平方向的像素数相乘：`2048 × 2048 = 4194304 pixels`。
2. 将像素总数乘以色彩深度：`4194304 × 16 = 67108864 bits`。
3. 将位数除以 `8`，得到文件的字节数：`67108864 / 8 = 8388608 bytes`。
4. 除以 `1024 × 1024` 转换为 MiB：`8388608 / 1048576 = 8 MiB`。

**示例 3**

一张音频 CD 的采样率为 `44100`，采样分辨率为 `16 bits`。采样音乐使用两个声道，以实现立体声录音。计算 60 分钟录音的文件大小。

1. 文件大小：

   ```text
   采样率（Hz）× 采样分辨率（位）× 样本长度（秒）
   ```

2. 样本大小：`44100 × 16 × (60 × 60) = 2540160000 bits`。
3. 使用两个声道，因此乘以 `2`：`5080320000 bits`。
4. 除以 `8` 得到字节数：`5080320000 / 8 = 635040000 bytes`。
5. 除以 `1024 × 1024` 转换为 MiB：`635040000 / 1048576 = 605 MiB`。
