<ParagraphTitle id="1-1-3-use-of-the-hexadecimal-system">十六进制系统的用途</ParagraphTitle>

<ParagraphContent id="1-1-3-use-of-the-hexadecimal-system">

如前所述，计算机只能处理二进制数据。虽然计算机科学家能够使用二进制，但十六进制更方便，因为一个十六进制数字代表四个二进制数字。复杂的二进制数（如 `1101001010101111`）可写成十六进制数 `D2AF`。十六进制数更容易让人记忆、抄写和处理。本节回顾十六进制系统的四种用途：

- 错误代码
- MAC 地址
- IPv6 地址
- HTML 颜色代码

本节内容足以让读者掌握这些主题在本课程层次上的基础知识。可通过互联网查找更多资料，但应避免偏离主题。

### 错误代码

错误代码通常显示为十六进制值。这些数值指向发生错误的内存位置，且通常由计算机自动生成。程序员需要能够解释十六进制错误代码。下方展示了 Windows 系统错误代码的示例。

### 媒体访问控制（MAC）地址

媒体访问控制（Media Access Control，MAC）地址是唯一标识网络中设备的编号。MAC 地址对应于设备中的网络接口卡（NIC）。MAC 地址很少变更，因此无论设备位于何处，都可以识别该设备。

MAC 地址通常由 48 位组成，显示为 6 组两个十六进制数字（也存在 64 位地址）：

```text
NN-NN-NN-DD-DD-DD
```

或：

```text
NN:NN:NN:DD:DD:DD
```

其中，前半部分（`NN-NN-NN`）是设备制造商的身份编号，后半部分（`DD-DD-DD`）是设备编号。
