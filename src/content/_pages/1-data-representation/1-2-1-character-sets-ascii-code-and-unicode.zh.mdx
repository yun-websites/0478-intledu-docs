<ParagraphTitle id="1-2-1-character-sets-ascii-code-and-unicode">字符集：ASCII 码与 Unicode</ParagraphTitle>

<ParagraphContent id="1-2-1-character-sets-ascii-code-and-unicode">

ASCII 编码系统（American Standard Code for Information Interchange，信息交换美国标准代码）于 1963 年建立，用于通信系统和计算机系统。该编码的较新版本于 1986 年发布。标准 ASCII 字符集由 7 位代码构成，可表示十进制 `0` 至 `127` 或十六进制 `00` 至 `7F`。它表示标准键盘上的字母、数字和字符，以及 32 个控制代码；控制代码使用十进制 `0` 至 `31` 或十六进制 `00` 至 `19`。
