<ParagraphTitle id="8-1-3-input-and-output">输入和输出</ParagraphTitle>

<ParagraphContent id="8-1-3-input-and-output">
程序使用输入和输出语句来接收数据并显示结果。IGCSE 计算机科学要求能够编写从键盘读取输入、向屏幕输出结果的算法和程序。

为了让程序易于使用，每项输入都应配有提示，说明用户需要输入什么。输入数据的类型必须与保存它的变量类型匹配。输入通常默认为字符串；如果需要整数或实数，就必须使用类型转换，例如 Python 中的 `int()` 或 `float()`。

```python
radius = float(input("Please enter the radius of the cylinder "))
```

这种把一种数据类型转换为另一种数据类型的技术称为**类型转换**（casting）。不同语言的输入语句形式不同，但都应明确提示用户并把输入保存到正确类型的变量中。
</ParagraphContent>
