<ParagraphTitle id="8-1-2-basic-data-types">基本数据类型</ParagraphTitle>

<ParagraphContent id="8-1-2-basic-data-types">
为了有效处理和存储数据，计算机系统会为不同种类的数据指定不同类型。这样可以：

- 用合适的方式存储数据，例如把数据存为数字或字符；
- 有效处理数据，例如对数字使用数学运算符，对字符进行连接；
- 在某些情况下自动完成验证。

IGCSE 计算机科学需要掌握以下基本数据类型：

- **integer（整数）**：可使用数学运算符的正数或负整数；
- **real（实数）**：带小数部分的正数或负数，可使用数学运算符；
- **char（字符）**：只包含一个字符的变量或常量；
- **string（字符串）**：包含多个字符的变量或常量，也可以是没有字符的空字符串。字符可以是字母、数字或其他可打印符号；如果数字以字符串形式保存，就不能直接用于计算；
- **Boolean（布尔值）**：只能取 `TRUE` 或 `FALSE` 两个值的变量或常量。

| 伪代码 | Python | Visual Basic | Java |
| --- | --- | --- | --- |
| `INTEGER` | `FirstInteger = 25` | `Dim FirstInt As Integer` | `int FirstInt;` |
| `REAL` | `FirstReal = 25.0` | `Dim FirstReal As Decimal` | `float FirstReal;` |
| `CHAR` | `Female = 'F'` | `Dim Female As Char` | `char Female;` |
| `STRING` | `FirstName = "Emma"` | `Dim FirstName As String` | `String FirstName;` |
| `BOOLEAN` | `Flag = True` | `Dim Flag As Boolean` | `boolean Flag;` |
