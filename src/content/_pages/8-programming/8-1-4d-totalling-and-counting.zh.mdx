<ParagraphTitle id="8-1-4d-totalling-and-counting">累计和计数</ParagraphTitle>

<ParagraphContent id="8-1-4d-totalling-and-counting">
累计和计数是第 7 章介绍的标准方法。

累计在 Python、Visual Basic 和 Java 中的基本形式相似：

```text
TotalWeight <- TotalWeight + Weight
```

计数也可以通过给变量加 1 实现：

```text
NumberOfItems <- NumberOfItems + 1
NumberOfItems += 1
NumberOfItems++
```

具体语法取决于编程语言。可以使用条件控制循环，让用户输入大米袋的重量；当用户输入 `-1` 时停止，然后输出输入的袋数和总重量。
</ParagraphContent>
