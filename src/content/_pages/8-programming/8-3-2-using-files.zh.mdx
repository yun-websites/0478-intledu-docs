<ParagraphTitle id="8-3-2-using-files">使用文件</ParagraphTitle>

<ParagraphContent id="8-3-2-using-files">
每个文件都由文件名标识。程序可以把文本行或单个数据项写入文件，也可以从文件中读回数据。

```text
DECLARE TextLine : STRING
DECLARE MyFile : STRING
MyFile <- "MyText.txt"

OPEN MyFile FOR WRITE
OUTPUT "请输入一行文本"
INPUT TextLine
WRITEFILE, TextLine
CLOSEFILE(MyFile)

OPEN MyFile FOR READ
READFILE, TextLine
OUTPUT TextLine
CLOSEFILE(MyFile)
```

使用 Python 时，可以通过打开模式 `w` 写入文件，再使用模式 `r` 读取文件：

```python
MyFile = open("MyText.txt", "w")
TextLine = input("Please enter a line of text ")
MyFile.write(TextLine)
MyFile.close()

MyFile = open("MyText.txt", "r")
TextLine = MyFile.read()
print(TextLine)
MyFile.close()
```

写入完成后应关闭文件，读取完成后也应关闭文件，以确保数据正确保存并释放文件资源。
