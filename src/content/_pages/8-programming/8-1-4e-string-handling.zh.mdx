<ParagraphTitle id="8-1-4e-string-handling">字符串处理</ParagraphTitle>

<ParagraphContent id="8-1-4e-string-handling">
字符串用于保存文本，可以为空，也可以包含编程语言允许的最大字符数。字符串中的字符可按位置编号；第一个字符的位置可能是 0 或 1，取决于编程语言。

需要掌握的字符串处理方法包括：

- **length**：查找字符数量；`"Computer Science"` 的长度是 16，因为空格也算一个字符；
- **substring**：提取字符串的一部分，例如从 `"Computer Science"` 提取 `"Science"`；
- **upper**：把所有字母转换为大写，例如 `"COMPUTER SCIENCE"`；
- **lower**：把所有字母转换为小写，例如 `"computer science"`。

这些方法通常由编程语言的库程序提供。常见写法包括伪代码中的 `LENGTH(MyString)`、Python 中的 `len(MyString)`、Visual Basic 中的 `MyString.Length()` 和 Java 中的 `MyString.length()`。
</ParagraphContent>
