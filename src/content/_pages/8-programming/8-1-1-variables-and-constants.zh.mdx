<ParagraphTitle id="8-1-1-variables-and-constants">变量和常量</ParagraphTitle>

<ParagraphContent id="8-1-1-variables-and-constants">
程序使用的数据可能有固定值，也可能在程序运行期间改变。**变量**是保存数据的命名存储位置，其值可以改变；**常量**也是命名存储位置，但其值在程序运行期间不会改变。变量和常量都应使用有意义的名称，以便他人理解程序。

并非所有编程语言都明确区分常量和变量，但程序员应清楚哪些存储位置可以修改、哪些不能修改。常见的常量命名方式包括使用大写字母，例如 `PI = 3.142`，或使用以 `Const` 开头的有意义名称，例如 `ConstPi = 3.142`。

良好做法是在程序中声明要使用的变量和常量。有些语言要求显式声明数据类型；另一些语言根据赋给变量的值隐式确定数据类型。声明可以放在程序开头，也可以放在数据第一次使用之前。

```text
DECLARE FirstVar : INTEGER
DECLARE SecondVar : INTEGER
CONSTANT FirstConst <- 500
CONSTANT SecondConst <- 100
```

在 Python 中通常不需要单独声明，也不明确区分常量和变量；程序员需要自行遵守命名约定并管理这种差异。Visual Basic 等语言则通常要求在使用前显式声明变量的数据类型。
</ParagraphContent>
