<ParagraphTitle id="7-5-1-validation">验证</ParagraphTitle>

<ParagraphContent id="7-5-1-validation">
**验证**是程序在接受数据进入计算机系统前，自动检查数据是否合理的过程。如果数据被拒绝，系统应说明拒绝原因，并允许用户重新输入。

常见验证检查包括：

- 范围检查；
- 长度检查；
- 类型检查；
- 存在性检查；
- 格式检查；
- 校验数字。

同一数据可以使用多种检查。例如，考试分数可以同时进行范围检查、类型检查和存在性检查。

### 范围检查

范围检查确认数值处于给定的上下限之间。例如，百分制分数必须在 0 至 100（含边界）之间：

```text
REPEAT
    INPUT StudentMark
    IF StudentMark < 0 OR StudentMark > 100 THEN
        OUTPUT "分数必须在 0 到 100 之间，请重新输入"
    ENDIF
UNTIL StudentMark >= 0 AND StudentMark <= 100
```

### 长度检查

长度检查确认数据包含准确数量的字符。例如，规定密码必须正好包含 8 个字符，就会拒绝 7 个或更少、9 个或更多字符的密码。
</ParagraphContent>
