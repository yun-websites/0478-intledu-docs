<ParagraphTitle id="7-4-4-linear-search">线性搜索</ParagraphTitle>

<ParagraphContent id="7-4-4-linear-search">
搜索用于检查列表中是否保存了某个值。**线性搜索**从列表第一项开始，依次检查每一项是否与要查找的值匹配，直到找到匹配项或检查完整个列表。

例如，在所有姓名不同的班级名单中搜索姓名：

```text
OUTPUT "请输入要查找的姓名"
INPUT Name
Found <- FALSE
Counter <- 1
REPEAT
    IF Name = StudentName[Counter] THEN
        Found <- TRUE
    ELSE
        Counter <- Counter + 1
    ENDIF
UNTIL Found OR Counter > ClassSize

IF Found THEN
    OUTPUT Name, " 位于列表中的位置 ", Counter
ELSE
    OUTPUT Name, " 未找到"
ENDIF
```

程序使用布尔变量 `Found` 作为标志，使用 `Counter` 记录当前位置，并在找到姓名或搜索完列表后停止。
</ParagraphContent>
