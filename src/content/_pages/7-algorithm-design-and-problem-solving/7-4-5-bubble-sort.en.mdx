<ParagraphTitle id="7-4-5-bubble-sort">Bubble sort</ParagraphTitle>

<ParagraphContent id="7-4-5-bubble-sort">
Lists are often more useful when their items are sorted into a meaningful order. For example, names can be sorted alphabetically and temperatures can be sorted in ascending or descending order.

A **bubble sort** compares each element with the next element and swaps them when they are in the wrong order. The first pass compares the first element with the next, then the second with the third, and so on until the next-to-last element is reached. The largest item then occupies the final position. The next pass ignores that final item and repeats the comparisons. The process stops when only one item remains to check or when a complete pass makes no swaps.

The following pseudocode sorts ten temperatures into ascending order:

```text
First <- 1
Last <- 10
REPEAT
    Swap <- FALSE
    FOR Index <- First TO Last - 1
        IF Temperature[Index] > Temperature[Index + 1] THEN
            Temp <- Temperature[Index]
            Temperature[Index] <- Temperature[Index + 1]
            Temperature[Index + 1] <- Temp
            Swap <- TRUE
        ENDIF
    NEXT Index
    Last <- Last - 1
UNTIL (NOT Swap) OR Last = 1
```

`Swap` records whether any pair was exchanged. If no exchange occurs, the list is already sorted.
