<ParagraphTitle id="7-4-5-bubble-sort">冒泡排序</ParagraphTitle>

<ParagraphContent id="7-4-5-bubble-sort">
如果列表中的项目按有意义的顺序排列，使用起来会更方便。例如，姓名可以按字母顺序排列，温度可以按升序或降序排列。**冒泡排序**从第一个元素开始，把每个元素与下一个元素比较；如果顺序错误，就交换它们。到达列表末尾时，最后一个元素必定已经位于正确位置。然后重复这一过程，但不再检查已经排好位置的末尾元素，直到只剩一个元素需要检查，或某一轮没有发生交换。

下面的伪代码把数组 `Temperature[]` 中的 10 个温度按升序排列：

```text
First <- 1
Last <- 10
REPEAT
    Swap <- FALSE
    FOR Index <- First TO Last - 1
        IF Temperature[Index] > Temperature[Index + 1] THEN
            Temp <- Temperature[Index]
            Temperature[Index] <- Temperature[Index + 1]
            Temperature[Index + 1] <- Temp
            Swap <- TRUE
        ENDIF
    NEXT Index
    Last <- Last - 1
UNTIL (NOT Swap) OR Last = 1
```
