<ParagraphTitle id="7-4-3-maximum-minimum-and-average">最大值、最小值和平均值</ParagraphTitle>

<ParagraphContent id="7-4-3-maximum-minimum-and-average">
在列表中查找最大值和最小值是算法中常用的标准方法，例如查找班级学生的最高分和最低分。

```text
MaximumMark <- 0
MinimumMark <- 100
FOR Counter <- 1 TO ClassSize
    IF StudentMark[Counter] > MaximumMark THEN
        MaximumMark <- StudentMark[Counter]
    ENDIF
    IF StudentMark[Counter] < MinimumMark THEN
        MinimumMark <- StudentMark[Counter]
    ENDIF
NEXT Counter
```

如果事先不知道可能的最大值和最小值，可以把列表的第一个元素同时作为初始最大值和最小值，然后从第二个元素开始比较：

```text
MaximumMark <- StudentMark[1]
MinimumMark <- StudentMark[1]
FOR Counter <- 2 TO ClassSize
    IF StudentMark[Counter] > MaximumMark THEN
        MaximumMark <- StudentMark[Counter]
    ENDIF
    IF StudentMark[Counter] < MinimumMark THEN
        MinimumMark <- StudentMark[Counter]
    ENDIF
NEXT Counter
```

计算列表中所有值的平均值是累计方法的延伸：先把所有值相加，再用总和除以值的数量。

```text
Total <- 0
FOR Counter <- 1 TO ClassSize
    Total <- Total + StudentMark[Counter]
NEXT Counter
Average <- Total / ClassSize
```
