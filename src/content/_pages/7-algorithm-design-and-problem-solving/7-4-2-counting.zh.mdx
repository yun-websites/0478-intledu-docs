<ParagraphTitle id="7-4-2-counting">计数</ParagraphTitle>

<ParagraphContent id="7-4-2-counting">
计数是统计某个动作执行次数的标准方法。例如，统计获得及格分数的学生人数：

```text
PassCount <- 0
FOR Counter <- 1 TO ClassSize
    INPUT StudentMark
    IF StudentMark > 50 THEN
        PassCount <- PassCount + 1
    ENDIF
NEXT Counter
```

计数也可用于倒计数，直到达到某个值。例如，检查超市库存数量：

```text
NumberInStock <- NumberInStock - 1
IF NumberInStock < 20 THEN
    CALL Reorder()
ENDIF
```
</ParagraphContent>
