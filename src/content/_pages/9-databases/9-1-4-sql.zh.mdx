<ParagraphTitle id="9-1-4-sql">SQL</ParagraphTitle>

<ParagraphContent id="9-1-4-sql">
结构化查询语言（Structured Query Language，SQL）是编写脚本、从数据库中获取有用信息的标准查询语言。本节使用 SQL 查询单表数据库，以理解如何只获取和显示所需信息。SQL 通常读作 “ess-cue-ell”。

SQL 脚本是执行特定任务的一组 SQL 命令，通常保存在文件中以便重复使用。Access、MySQL 和 SQLite 等应用程序都可以运行 SQL；具体可用命令可能略有不同。

| SQL 命令 | 作用 |
| --- | --- |
| `SELECT` | 指定要从表中获取的字段（列）；查询总是以 `SELECT` 开始。 |
| `FROM` | 指定要使用的表。 |
| `WHERE` | 只保留满足条件的记录（行）。 |
| `ORDER BY` | 按指定列对结果进行字母或数字排序。 |
| `SUM` | 返回字段中所有值的总和，与 `SELECT` 一起使用。 |
| `COUNT` | 统计字段满足指定条件的记录数，与 `SELECT` 一起使用。 |

SQL 命令通常以 `SELECT` 开始，接着写字段和 `FROM`，再指定表名，并以分号 `;` 结束。只有 `SELECT` 和 `FROM` 是必需的，其他命令都是可选的。

```sql
SELECT Field1, Field2, Field3
FROM TableName;
```

`SELECT Field1, Field2, Field3` 指定要显示的字段；`SELECT *` 表示选择所有字段。使用 `WHERE` 可以筛选满足条件的记录，使用 `ORDER BY` 可以对结果排序。
