<ParagraphTitle id="9-1-2-basic-data-types">基本数据类型</ParagraphTitle>

<ParagraphContent id="9-1-2-basic-data-types">
数据库中需要掌握六种基本数据类型：文本/字母数字、字符、布尔值、整数、实数和日期/时间。

每个字段都需要选择数据类型。数据类型规定数据如何存储和显示，以及可以对存储值执行哪些操作。例如，整数类型的字段以整数保存和显示，其值可以用于计算。

| 课程数据类型 | 说明 | Access 数据类型 |
| --- | --- | --- |
| text/alphanumeric | 一串字符 | short text / long text |
| character | 单个字符 | 字段大小为 1 的 short text |
| Boolean | 两个值之一：True/False 或 1/0 | Yes/No |
| integer | 整数 | 固定小数位为 0 的 number |
| real | 小数 | decimal number |
| date/time | 日期和/或时间 | Date/Time |

### 活动 9.2

使用 Access 或其他数据库管理软件建立单表数据库，保存 PATIENT（患者）记录，字段包括 `FirstName`、`FamilyName`、`DateOfAdmission`、`Consultant`、`WardNumber` 和 `BedNumber`。为每个字段选择合适的数据类型，并验证病房号只能是 1 至 10 的整数、床位号只能是 1 至 8 的整数。
</ParagraphContent>
