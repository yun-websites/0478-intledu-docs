<ParagraphTitle id="5-1-4-web-browsers">网页浏览器</ParagraphTitle>

<ParagraphContent id="5-1-4-web-browsers">
网页浏览器是允许用户访问网页并在设备屏幕上显示网页的软件。浏览器会解释网站中的 HTML，并显示解释后的结果，例如视频、图像、文字和音频。

浏览器通常具有以下功能：

- 提供主页；
- 保存用户喜爱的网站或网页，即书签；
- 保存用户访问过的网站历史记录；
- 允许用户在已打开的网页之间前进和后退；
- 通过多个标签页同时打开多个网页；
- 使用 Cookie；
- 使用超链接在网站和网页之间导航，链接可以在新标签页或当前标签页中打开；
- 使用缓存保存数据；
- 支持 JavaScript；
- 提供地址栏。

HTML（超文本标记语言）用于在浏览器中显示内容。网站使用 HTML 编写，并托管在具有自身 IP 地址的网页服务器上。浏览器要获取网页，必须知道服务器的 IP 地址。

**域名服务器**（Domain Name Server，DNS）根据 URL 中的域名查找对应的 IP 地址。URL 和 DNS 免除了用户记忆 IP 地址的需要。例如，DNS 可以把 `www.hoddereducation.co.uk` 转换为计算机能够理解的 `107.162.140.19`。DNS 过程可能涉及多个服务器。
</ParagraphContent>
