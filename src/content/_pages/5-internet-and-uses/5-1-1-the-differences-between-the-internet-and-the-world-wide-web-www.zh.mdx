<ParagraphTitle id="5-1-1-the-differences-between-the-internet-and-the-world-wide-web-www">互联网与万维网的区别</ParagraphTitle>

<ParagraphContent id="5-1-1-the-differences-between-the-internet-and-the-world-wide-web-www">
“互联网”（internet）来自 interconnected network，指全球互相连接的网络集合。互联网更像一个概念，而不是可以触摸的实体；它依赖物理基础设施，让网络和设备彼此连接。

**万维网**（World Wide Web，WWW）只是互联网的一部分，用户可以通过网页浏览器访问它。万维网由大量网页组成，基于超文本传输协议（HTTP）。因此，万维网是使用互联网访问信息的一种方式，互联网和万维网并不相同。

| 互联网 | 万维网（WWW） |
| --- | --- |
| 可以发送和接收电子邮件 | 由网站中的多媒体网页和其他信息组成 |
| 支持文字、音频和视频聊天 | HTTP(S) 协议使用 HTML 编写 |
| 使用 TCP 和 IP 等传输协议 | 使用 URL 指定网页位置 |
| 是全球互相连接的网络和设备集合 | 通过网页浏览器访问网页资源 |
| 不局限于网页服务 | 使用互联网从网页服务器访问信息 |
</ParagraphContent>
