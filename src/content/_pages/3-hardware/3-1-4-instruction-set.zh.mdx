<ParagraphTitle id="3-1-4-instruction-set">指令集</ParagraphTitle>

<ParagraphContent id="3-1-4-instruction-set">
在计算机系统中，指令是一组按顺序译码的操作。每项操作都会向 CPU 中的 ALU 和 CU 发出指示。一项操作由**操作码**（opcode）和**操作数**（operand）组成：

- 操作码告诉 CPU 要执行什么操作；
- 操作数是要处理的数据，或者指向内存中的某个寄存器。

计算机能够理解和执行的操作码数量有限，这组操作码称为**指令集**。在计算机上运行的所有软件都包含一组指令，且这些指令必须转换为二进制。CPU 通过“取指、译码、执行”循环依次处理每条指令。

X86 是一种常见的 CPU 指令集标准，广泛用于现代计算机。不同制造商可以采用不同的内部电子设计，但只要基于 X86 CPU，指令集就几乎相同。例如，Intel Pentium 和 AMD Athlon CPU 虽然内部电子设计不同，却使用几乎相同的 X86 指令集。

不要把指令集与程序代码混淆。指令集是指导 CPU 执行操作的低级语言指令；程序代码需要通过解释器或编译器转换为计算机能理解的指令集。常见指令包括 `ADD`、`JMP` 和 `LDA`。
</ParagraphContent>
