<ParagraphTitle id="3-3-3-magnetic-optical-and-solid-state-storage">磁性、光学和固态存储</ParagraphTitle>

<ParagraphContent id="3-3-3-magnetic-optical-and-solid-state-storage">
辅助和离线存储按使用的技术分为三类：

- 磁性存储；
- 固态存储；
- 光学存储。

### 磁性存储：硬盘驱动器（HDD）

硬盘驱动器仍是计算机中常见的数据存储方式之一。数据以数字格式保存在磁性磁盘表面，磁盘也常称为盘片（platter）。硬盘通常有多个盘片；读写头由电磁铁组成，用于从盘片读取数据或向盘片写入数据。盘片可由铝、玻璃或陶瓷材料制成，通常每个盘片的两面都可存储数据。

数据按**磁道**和**扇区**保存。给定磁道上的一个扇区包含固定数量的字节。读写头需要不断移动以寻找正确的数据块；与 RAM 相比，这使硬盘的数据访问速度较慢。

**延迟**（latency）是数据磁道上的特定数据块旋转到读写头下方所需的时间。用户看到“请等待”或“无响应”等消息时，往往能感受到延迟的影响。文件或数据保存到 HDD 时，系统会分配足够数量的扇区来存储它。
