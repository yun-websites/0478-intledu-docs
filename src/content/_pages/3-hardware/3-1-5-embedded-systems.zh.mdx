<ParagraphTitle id="3-1-5-embedded-systems">嵌入式系统</ParagraphTitle>

<ParagraphContent id="3-1-5-embedded-systems">
**嵌入式系统**是为执行一组特定功能而设计的硬件和软件组合；其硬件可以是电子、电气或机电设备。嵌入式系统可基于：

- **微控制器**：在单个芯片上集成 CPU、部分 RAM、ROM 和其他外设；
- **微处理器**：芯片上只有 CPU，RAM、ROM 和外设需要另外添加；
- **片上系统**（system on a chip，SoC）：通常在单一微芯片上集成 CPU、内存、输入/输出端口和辅助存储器，并可能包含微控制器。

嵌入式系统具有专门任务，通常是反馈导向的系统。它可接收模拟或数字输入、运行嵌入式软件和硬件，并产生输出；其中可包括传感器、机械部件、执行器和软件。

设备安装嵌入式系统后，操作员可以手动输入数据，例如在烤箱控制面板上通过键盘选择温度或转动旋钮；输入也可来自传感器等自动来源，例如汽车发动机管理系统中的氧气浓度或燃油压力。系统会向受控部件发送信号完成任务，例如提高烤箱加热元件的功率，或降低发动机中的燃油水平。

嵌入式系统可以是可编程或不可编程的。不可编程设备需要软件升级时通常必须更换；可编程设备可通过连接计算机下载安装更新，或经 Wi-Fi、卫星或蜂窝网络自动更新。

### 优点和缺点

| 优点 | 缺点 |
| --- | --- |
| 体积小，易于装入设备 | 某些设备难以升级以利用新技术 |
| 制造成本相对较低 | 故障排查需要专业人员 |
| 通常专用于一项任务，界面简单，往往不需要操作系统 | 看似简单的界面可能反而难用，例如设置炊具时钟需要多个步骤 |
| 功耗很低 | 可通过互联网访问的设备也面临黑客和病毒风险 |
| 可用手机远程控制 | 因升级和维修困难，设备常被丢弃而非修理，造成浪费 |
| 对输入变化反应快，可实时运行 | 设备过时即丢弃会增加一次性消费问题 |

由于可以连接互联网，嵌入式系统可通过智能手机或计算机远程控制，例如离家时开关中央供暖，或远程指示机顶盒录制节目。工程师可针对专用任务优化设计，以减小设备体积和成本。应用范围从 MP3 播放器中的单个微控制器，到医疗成像系统中的多个复杂单元。

通用计算机不是嵌入式系统，因为计算机是多功能设备，能够通过不同软件执行许多不同任务。
