<ParagraphTitle id="3-4-1-network-interface-card-nic">网络接口卡（NIC）</ParagraphTitle>

<ParagraphContent id="3-4-1-network-interface-card-nic">
设备要连接网络（例如互联网），需要使用**网络接口卡**（network interface card，NIC）。NIC 通常是设备硬件的一部分，并包含在制造阶段生成的媒体访问控制地址（MAC address）。

无线网络接口卡或控制器（wireless network interface card/controller，WNIC）与普通 NIC 的作用相同，都是把设备连接到互联网或其他网络。但 WNIC 使用无线连接，通过天线利用微波与网络通信。WNIC 通常插入 USB 端口，或集成在设备内部的集成电路中。
</ParagraphContent>
