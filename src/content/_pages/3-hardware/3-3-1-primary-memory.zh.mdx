<ParagraphTitle id="3-3-1-primary-memory">主存储器</ParagraphTitle>

<ParagraphContent id="3-3-1-primary-memory">
**主存储器**是 CPU 可以直接访问的存储器，包括随机存取存储器（RAM）和只读存储器（ROM）。CPU 可通过主存储器访问暂时存放在内存位置中的应用程序和服务。

### 随机存取存储器（RAM）

RAM 中任意内存位置都能被直接访问，不依赖于上一次访问的位置。运行应用程序时，数据会从辅助存储器取出并暂时放入 RAM；RAM 的访问速度远快于辅助或离线存储设备。

RAM 的特点：

- 可以读写，数据可由用户或计算机改变；
- 保存当前正在使用的数据、文件、应用程序的一部分或操作系统的一部分；
- 是**易失性**存储器，计算机关机后内容会丢失。

通常 RAM 容量越大，计算机运行越快。RAM 接近满载时，CPU 必须频繁访问辅助存储器，用新数据覆盖 RAM 中较早的数据，导致系统变慢；增加 RAM 可减少这种交换操作。

RAM 主要有两种技术：动态 RAM（DRAM）和静态 RAM（SRAM）。
</ParagraphContent>
