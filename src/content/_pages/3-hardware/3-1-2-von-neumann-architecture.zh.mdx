<ParagraphTitle id="3-1-2-von-neumann-architecture">冯·诺依曼体系结构</ParagraphTitle>

<ParagraphContent id="3-1-2-von-neumann-architecture">
早期计算机在运行时才输入数据，不能存储程序或数据，因此需要大量人工干预。20 世纪 40 年代中期，John von Neumann 提出了**存储程序计算机**的概念，此后一直是计算机体系结构的基础。

冯·诺依曼体系结构的主要新特征包括：

- 引入中央处理器（CPU 或处理器）；
- CPU 可以直接访问内存；
- 内存既可存储程序，也可存储数据；
- 存储的程序由可按顺序执行的指令组成。

CPU 主要包括控制单元（CU）、算术逻辑单元（ALU）和系统时钟。ALU 执行算术运算，例如加、减和移位，也执行逻辑运算，例如 `AND` 和 `OR`。乘法和除法可由一系列加法、减法和逻辑左移或右移操作完成。

控制单元从内存读取指令。程序计数器（program counter，PC）存储下一条指令所在的内存地址。控制单元通过“取指、译码、执行”循环解释指令，并沿控制总线发送信号，指示其他部件执行相应操作。系统时钟在控制总线上产生时序信号，确保数据流和程序指令在整个计算机中同步；没有时钟，计算机将无法正常工作。

RAM 保存 CPU 需要访问的程序和数据，也称为**即时访问存储器**（Immediate Access Store，IAS）。CPU 会把后备存储器（例如硬盘驱动器）中的程序和数据暂时放入 RAM，因为 RAM 的读写速度远快于后备存储器。

### 专用寄存器

| 寄存器 | 缩写 | 用途 |
| --- | --- | --- |
| 当前指令寄存器 | CIR | 保存当前正在译码和执行的指令。 |
| 累加器 | ACC | 在 ALU 进行计算时临时保存数据。 |
| 内存地址寄存器 | MAR | 保存当前要读取或写入的内存位置地址。 |
| 内存数据寄存器/缓冲寄存器 | MDR | 保存刚从内存读取的数据，或即将写入内存的数据。 |
| 程序计数器 | PC | 保存下一条要读取的指令所在地址。 |

### 系统总线

系统总线连接 CPU、内存和输入/输出设备，由三类总线组成：

- **控制总线**：传送控制和时序信号；
- **地址总线**：传送要访问的内存位置地址；
- **数据总线**：传送数据和指令。
