<ParagraphTitle id="3-3-2-secondary-and-off-line-storage">辅助与离线存储</ParagraphTitle>

<ParagraphContent id="3-3-2-secondary-and-off-line-storage">
**辅助存储器**和**离线存储器**包含 CPU 无法直接寻址的存储设备。它们是**非易失性**设备，能够在用户需要的时间内持续保存数据。

与主存储器相比，辅助存储器可以保存更多数据，但访问时间比 RAM 或 ROM 长得多。操作系统、应用程序、设备驱动程序，以及文档、照片和音乐等普通文件，都会保存在辅助存储器中。
</ParagraphContent>
