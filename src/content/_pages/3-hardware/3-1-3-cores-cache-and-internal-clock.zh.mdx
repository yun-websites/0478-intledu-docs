<ParagraphTitle id="3-1-3-cores-cache-and-internal-clock">核心、缓存和内部时钟</ParagraphTitle>

<ParagraphContent id="3-1-3-cores-cache-and-internal-clock">
CPU 性能受多个因素影响。系统时钟定义**时钟周期**，使计算机的各项操作同步。控制总线传送时序信号来保证同步。提高时钟频率会提高处理速度；例如 `3.5 GHz` 表示每秒 35 亿个时钟周期。但更高的时钟频率不必然意味着整体性能更高，还要考虑其他因素。

- 地址总线和数据总线的宽度会影响性能；更宽的总线可在一次传输中处理更多地址或数据。
- **超频**可通过修改 BIOS（基本输入/输出系统）设置来改变时钟频率。频率超过设计限制可能导致指令无法在下一条指令执行前完成，从而造成不同步、频繁崩溃和不稳定；超频还可能使 CPU 严重过热，导致性能不可靠。
- **缓存**位于 CPU 内部，数据访问速度远快于 RAM。它保存常用的指令和数据；CPU 读取内存时会先检查缓存，未找到才访问主存/RAM。缓存容量越大，CPU 性能通常越好。
- 一个**核心**由 ALU、控制单元和寄存器组成。双核 CPU 有两个核心，四核 CPU 有四个核心。更多核心可减少单纯提高时钟频率的需求，但核心数加倍不一定使性能加倍，因为 CPU 仍需与各核心通信，这会产生额外开销。

因此，提高数据和地址总线宽度、适当提高时钟频率、使用缓存和多核 CPU 都可能提高计算机性能。
