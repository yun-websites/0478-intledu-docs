<ParagraphTitle id="3-3-4-virtual-memory">虚拟内存</ParagraphTitle>

<ParagraphContent id="3-3-4-virtual-memory">
内存管理的一个问题是运行中的进程耗尽 RAM。当多个程序同时运行而超出可用 RAM 时，系统可能崩溃。解决方法是利用硬盘驱动器或 SSD 提供额外空间，这就是**虚拟内存**的基础。

RAM 是物理内存；虚拟内存则是 RAM 与硬盘或 SSD 上的**交换空间**（swap space）的组合。程序执行时，所需数据会从 HDD 或 SSD 加载到内存；当 RAM 空间不足时，暂时不需要的数据会被移出到交换空间，其他所需数据再被加载到 RAM。

### 不使用虚拟内存

假设内存中有编号为 `0` 至 `4` 的五个程序，都需要访问 RAM。如果不使用虚拟内存，前四个程序占满 RAM 后，程序 `4` 无法获得可用空间，从而导致系统崩溃。

### 使用虚拟内存

使用虚拟内存时，CPU 可以把 RAM 中暂时不需要的数据移到 HDD 或 SSD，再把当前需要的数据移入 RAM。程序地址空间通过映射关系对应到物理 RAM 地址，因此所有程序都可以在需要时使用 RAM，而不必同时完整驻留在 RAM 中。

虚拟内存能够让计算机运行需要较大内存空间的多个程序，但由于 HDD 或 SSD 的访问速度低于 RAM，频繁交换数据会降低系统性能。
