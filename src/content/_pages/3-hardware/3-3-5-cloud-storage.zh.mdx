### 公有云和私有云计算

**云存储**是把数据保存在远程服务器上的存储方式。为便于维护或修理，同一数据会保存在多台服务器上，这称为**数据冗余**。物理环境由托管公司拥有和管理，可能包含分布在多个地点的数百台服务器。

常见的云存储系统有三种：

- **公有云**：客户与云存储提供商是不同的公司；
- **私有云**：存储环境专门为某家公司提供，位于公司防火墙之后；客户与提供商整合为一个实体运营；
- **混合云**：结合公有云和私有云，部分数据保存在私有云，敏感性或商业性较低的数据可放在公有云中。

用户不必把数据保存到本地硬盘或其他存储设备，而可以将数据保存“在云端”。

### 云存储的优点和缺点

| 优点 | 缺点 |
| --- | --- |
| 只要能上网，客户可以随时随地从任意设备访问云端文件 | 网络连接缓慢或不稳定时，访问和下载数据会遇到问题 |
| 不需要随身携带外部存储设备，也不必使用同一台计算机保存和读取数据 | 大容量存储可能费用较高；互联网服务提供商的上传和下载流量限制也可能收费 |
| 云端提供远程备份，有助于减少数据丢失并进行灾难恢复 | 云存储公司可能发生故障，存在丢失全部备份数据的风险 |
| 本地硬盘或备份设备损坏时，可以从云端恢复数据 | 使用云存储依赖网络连接和服务提供商的持续可用性 |
