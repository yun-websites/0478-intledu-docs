<ParagraphTitle id="2-2-3-check-digits">校验数字</ParagraphTitle>

<ParagraphContent id="2-2-3-check-digits">
**校验数字**（check digit）是代码中的最后一位，由代码中的其他所有数字计算得出。商品条形码、国际标准书号（ISBN）和车辆识别号码（VIN）都会使用校验数字。

校验数字用于发现因输错数字或错误扫描条形码造成的数据输入错误，通常可以检测出：

- 输入了错误数字，例如把 `5307` 输入成 `5327`；
- **换位错误**，即两个数字交换了位置，例如把 `5307` 输入成 `5037`；
- 漏输或多输数字，例如把 `5307` 输入成 `537` 或 `53107`；
- **语音错误**，例如把 30（thirty）听成 13（thirteen）。

```text
ISBN 978-0-340-98382-9
条形码：9780340983829
```

生成校验数字有多种方法，这里介绍两种常用方法：ISBN-13 和模 11（Modulo-11）。

### 示例 1：ISBN-13

ISBN-13 的校验数字是编号的第 13 位。下面分别说明如何生成校验数字，以及如何重新计算以验证校验数字。

#### 计算 1：由前 12 位生成校验数字

算法如下：

1. 将所有奇数位数字相加；
2. 将所有偶数位数字相加，并把结果乘以 3；
3. 将步骤 1 和步骤 2 的结果相加，再除以 10；
4. 取余数；如果余数为 0，就使用 0；否则用 10 减去余数，得到校验数字。

以 ISBN `978034098382` 为例：

```text
1. 9 + 8 + 3 + 0 + 8 + 8 = 36
2. 3 x (7 + 0 + 4 + 9 + 3 + 2) = 75
3. (36 + 75) / 10 = 111 / 10，余数为 1
4. 10 - 1 = 9，因此校验数字为 9
```

完整的 13 位 ISBN 是 `9780340983829`。

#### 计算 2：重新计算以验证 13 位 ISBN

验证含校验数字的 ISBN-13 时：

1. 将包括校验数字在内的所有奇数位数字相加；
2. 将所有偶数位数字相加，并把结果乘以 3；
3. 将两个结果相加，再除以 10；
4. 如果余数为 0，则该编号正确。

以 `9780340983829` 为例：

```text
1. 9 + 8 + 3 + 0 + 8 + 8 + 9 = 45
2. 3 x (7 + 0 + 4 + 9 + 3 + 2) = 75
3. (45 + 75) / 10 = 120 / 10，余数为 0
4. 余数为 0，因此编号正确。
```

### 示例 2：模 11

模 11 方法可处理不同长度的号码，适用于产品代码或 VIN 等应用。以下示例从 7 位原始号码 `4156710` 生成校验数字。

1. 从左到右为各位依次赋予权重 `8, 7, 6, 5, 4, 3, 2`；
2. 每一位乘以其权重，并将各结果相加；
3. 将总和除以 11；
4. 用 11 减去余数得到校验数字；如果结果为 10，则以 `X` 作为校验数字。

```text
(8 x 4) + (7 x 1) + (6 x 5) + (5 x 6) + (4 x 7) + (3 x 1) + (2 x 0)
= 32 + 7 + 30 + 30 + 28 + 3 + 0
= 130

130 / 11 = 11，余数为 9
11 - 9 = 2
```

因此完整的 8 位号码为 `41567102`。

要验证该 8 位号码，应从左到右使用权重 `8, 7, 6, 5, 4, 3, 2, 1`，将加权总和除以 11；余数为 0 时，号码正确。

```text
(8 x 4) + (7 x 1) + (6 x 5) + (5 x 6) + (4 x 7) + (3 x 1) + (2 x 0) + (1 x 2)
= 132

132 / 11 = 12，余数为 0
```
